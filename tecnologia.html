How a reading moves

Path of one reading

From the file to the line on the screen.

  1. Cloud StorageThe file hits Cloud Storage with the plot id.
  2. BigQueryThe pipeline writes a row in BigQuery and keeps what it dropped.
  3. Vertex AIVertex AI serves the pinned version for that crop.
  4. Cloud RunCloud Run returns the slip, or a miss.
  5. DashboardThe dashboard shows the line in the operation’s words.
